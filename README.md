# CourseGuide AI - Department Q&A Assistant


## Setup Instructions

1. **Install SWI-Prolog**:
   - Ubuntu/Debian: `sudo apt-get install swi-prolog`
   - macOS: `brew install swi-prolog`
   - Windows: Download installer from https://www.swi-prolog.org/ and append the `bin` directory to system `PATH`.

2. **Install Python Packages**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application**:
   ```bash
   python app.py
   ```
   Open `http://127.0.0.1:5000` in your web browser.

## Usage Instructions

1. Input your query related to the course you'd like to have answered
